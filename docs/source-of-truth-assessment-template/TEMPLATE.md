# Kage Source of Truth Assessment Template

## Status

APPROVED FOR LIMITED INTERNAL, NON-EXECUTING USE

## Purpose

Use this template to classify information in internal drafts, plans, research
briefs, and approval requests.

This template supports the limited internal use of:

```text
skills/kage-source-of-truth/SKILL.md
```

It does not authorize external-system access, Google Drive access, real-record
updates, external research, communications, publishing, financial activity,
contracting, access changes, automation, connector activation, agent activation,
or external execution.

## Permitted Use

- Internal information classification
- Internal draft preparation
- Internal planning support
- Internal research-brief support
- Internal approval-request preparation
- Identification of facts, directives, assumptions, conflicts, restricted
  information, and unknowns

## Prohibited Use

- Treating this template as a canonical Kage business record
- Recording secrets, credentials, payment information, bank details, contracts,
  personal data, or restricted operational data
- Using real external-system content without separately approved access
- Updating or overwriting a canonical record
- Sending, publishing, sharing, purchasing, signing, granting access, or taking
  any external action
- Inferring Founder approval from this template or from completion of an
  assessment

## Classification Guide

| Classification | Use When | Required Handling |
|---|---|---|
| Confirmed Fact | An item is verified in an appropriate canonical Kage source or explicitly confirmed by Founder | State the source and use only within supported scope |
| Founder Directive | Founder has issued an explicit instruction or decision | Follow only within the stated scope; record resulting canonical updates separately if approved |
| Approved Plan | A future action or strategy has explicit Founder approval | Use for preparation only; do not infer execution authority |
| Draft | Material is proposed, incomplete, or under review | Keep internal; do not present as final or approved |
| Research Finding | Material comes from external or non-canonical research | Label source, date, limits, and verification need |
| Assumption | A planning interpretation is needed but unverified | Make it explicit and request confirmation where material |
| Conflict | Two or more sources materially disagree | Surface the conflict; do not resolve silently |
| Restricted Information | Material is sensitive, private, financial, contractual, personal, or credential-related | Minimize, redact, and do not reproduce or distribute |
| Unknown | The needed information cannot be established | State that it is unknown; do not infer or estimate |

## Completion Rules

Before using an assessment:

- Separate facts from assumptions.
- Identify the source category and available evidence.
- State uncertainty, gaps, and conflicts.
- Do not claim a source was accessed unless it was actually supplied in the
  approved working context.
- Do not treat an external source as a canonical Kage record.
- Do not treat a draft as approved.
- Do not treat this template as Founder approval.
- Keep execution status as:

```text
No external action authorized
```

## Change Control

Changes to this template require:

1. Founder approval.
2. Review against `skills/kage-source-of-truth/SKILL.md`.
3. Review against `SECURITY.md`.
4. A changelog entry where applicable.
5. Continued non-executing status unless separately approved.
